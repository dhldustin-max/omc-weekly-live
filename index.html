📋 어떻게 사용해?
  1. 미팅 시작 전: 본인 이름 + 미팅 날짜 입력
  2. 매니저별 1:1 미팅마다: 위 파란 박스에서 매장 선택 → 그 매장 1개만 화면에 보임
  3. 매니저가 Labor $ + Food $ 알려주면 입력 → Prime % + Grade + Action Plan 즉시 자동
  4. 📋 Last Week's Notes (파란 박스): 지난주 액션 아이템들 → 매니저랑 같이 ✓ 체크 (완료된거)
  5. 📝 This Week's Notes (노란 박스): 이번주 새 액션 아이템 입력 + Add 버튼
  6. 11개 매장 다 끝나면 → "All Stores" → "📤 Upload to Drive" → ① Drive 탭 자동 오픈 ② state.json은 자동으로 Drive memory 폴더에 저장 (Apps Script 자동) ③ 인쇄창 → "PDF로 저장" → PDF만 Drive로 드래그하면 끝
  7. 다음주에 같은 브라우저로 열면 → 이번주 노트/Labor/Food가 "지난주" 자리에 자동으로 채워짐 (브라우저 localStorage + Drive memory 폴더 둘 다 백업됨)
  8. 다음주에 다시 열면 → 이번주 노트가 "Last Week's Notes"로 자동 표시 (사이클)
